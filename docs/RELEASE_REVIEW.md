角色示例重新编写；部分测试中的昵称、号码与媒体标识已改成合成数据。预设源中的私人设备及外部账号操作描述已移除，并重新生成对应 patch。原 LICENSE 完整保留。

## 为独立安装所做的整理

- 将已被语音模块静态导入的 `opencc-js` 声明为直接依赖，并更新锁文件。
- 语音工具默认路径改为仓库下的通用 `tools/`，仍可用环境变量指定。
- 管理员开发通道默认关闭，移除其写死的本机工作路径。
- 配置模板使用空身份、空白名单和空令牌；可选语音、主动话题、黑话自动研究保持关闭。
- 移除指向仓库外独立语音工具的 npm 启动入口，并在文档说明边界。
- 补齐隔离测试的运行模块；修正过时队列断言与脱敏测试标识，保留对实际行为的检查。
