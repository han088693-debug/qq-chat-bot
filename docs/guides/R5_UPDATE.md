# r5 更新与配置

本次同步本地 `v0.2.0-r5` 的增量功能，保留本仓库原有安装流程、空间巡逻、可选设备模块及安全默认值。没有打包个人配置、聊天数据、私人角色卡或外部图片素材。

## 表情与发送

- 新增表情情绪与角色筛选、品味笔记、收藏额度和按会话统计的发送额度。
- 外部图库从 `aigengtu.com` 获取公开索引与图片，经过地址、文件类型、尺寸和体积检查后缓存。仅用于私聊，不上传本地聊天文本给图库。图片本身不随源码分发，使用者自行确认使用权限。
- 文字、图片和表情共用会话冷却；需要“文字加表情”时，一次调用 `qq_send_message`，用 `messages` 加 `stickerId` 传入。
- 部分成功会返回已发送数量及表情失败信息；不要把已经发出的文字整批重发。
- `socialV2.sticker.external.enabled` 控制外部图库；`taste.enabled` 控制品味功能。`external.maxPerHourPerChat`、`external.maxPerDayPerChat` 与 `collect.maxPerDay` 分别限制外部表情和收藏频率。关闭外部图库不影响已有 QQ 收藏表情。

## 跨私聊记忆

`socialV2.crossMemory.enabled` 默认是 `false`。关闭时不会自动登记跨聊印象、刷新好友昵称缓存或把其他私聊的近况注入当前会话。

管理员明确需要跨聊共享时才将此项设为 `true`。启用后，已登记且在白名单中的其他私聊可能被引用，包括近期文字；这会改变不同私聊之间的信息隔离范围。`recordOnly: true` 仅限制来源为已登记联系人，不等同于每次共享都已获同意。默认不使用管理员私聊作为来源，群聊不参与共享。

关系资料保存在本机 `state/cross-memory.json`；修改开关后可重启桥接使配置生效。不要把该文件或其他 `state/` 数据提交到 Git。

## 升级与验证

先保存本机配置，再更新代码并执行 `npm ci`。将示例中需要的新字段合入自己的配置，不要直接覆盖正在使用的 `config.json`。

本仓库继续保留两分钟发送间隔示例、默认关闭的主动聊天、开发控制通道和可选空间自动操作。已有用户配置不会自动被改写。

离线验证：

```sh
npm run test:audit
npm run test:r5
npm run test:session-features
npm run test:optional
npm run test:patrol
```

这些测试使用夹具和模拟端点，不代表已完成真实 QQ 发消息、模型推理或空间操作的端到端验证。

## 控制台与运行维护更新

2026-10-23 的后续同步增加以下现有功能：

- 控制台健康面板展示连接、执行队列、会话上下文、用量估算和近期告警；运行日志与链路检查保留在管理端。
- 「会话与审批」可保存或清除单个会话的模型、思考强度覆盖。模式与预设仍由全局设置决定，不能用策略编辑器提升权限。
- 二代会话支持上下文预算：管理员私聊默认 600k、其他私聊 400k、群聊 300k tokens，可通过 `socialV2.context.ownerBudget`、`privateBudget`、`groupBudget` 调整。自动压缩还要求会话空闲、达到预算且冷却已结束；控制台的手动压缩仍拒绝忙碌会话。`socialV2.context.enabled=false` 可关闭这条压缩路径。压缩调用 DSH `/compact`，应按部署环境核对模型费用与兼容性。
- 沉睡前的安静窗口由服务端管理，新消息会取消等待；回复检查可被新消息接管，提醒合入下一次实际唤醒，减少重复轮次。`qq_send_message` 可携带 `throughSeq` 与 `nextWake` 合并收尾。
- 主动起话按自然日计数，额度耗尽后停止当日空转检查；发布模板仍默认关闭主动起话。
- 模型目录增加超时和缓存，表情预热延后到连接可用时执行；网页读取支持压缩响应和额外搜索回退。

这些改动不自动替换用户配置，不修改白名单，也不启用跨私聊记忆。聊天指标仍要求管理员明确选择会话，不会自动挑选另一段私聊。

压缩完成通知只释放可关联到同一命令的请求锁，迟到的旧通知不会释放新请求。运行时没有返回可关联编号，或完成通知早于命令响应时，状态会保留为 `queued-unverified`，直到 `socialV2.context.timeoutMs` 超时恢复；此时不能把“已受理”理解为“已完成”。

### 旧会话归档

在停止桥接并备份自己的配置与状态后，从仓库根目录运行：

```sh
npm run social:archive -- --preview
npm run social:archive -- --apply
```

默认只预览。实际归档针对不在白名单且超过七天未活动的会话，以及脚本明确列出的合成测试会话；应用前保留状态备份，归档保存于本机 `state/archive/`。恢复时使用 `--restore` 加自己的会话 key。活动会话不会被恢复操作覆盖；损坏或不可读的配置、状态、已有归档会阻止写入。

归档包含原始会话数据，必须留在本机。不要把归档、备份或命令输出随代码上传。

### 代理 fake-IP

默认保留原有网络地址限制及腾讯媒体域名的既有例外。只有明确使用可信本机代理时，才可设置 `SAFE_FETCH_ALLOW_FAKE_IP=1` 放行泛域名的代理 fake-IP；`SAFE_FETCH_BLOCK_FAKE_IP=1` 优先强制禁用该例外。显式 IP 地址、私网地址和其他 SSRF 检查仍保留。
